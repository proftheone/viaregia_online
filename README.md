# viaregia.online

Statyczny landing page domeny viaregia.online, który pokazuje, że VIAREGIA.ONLINE Sp. z o.o. jest właścicielem marek Otoneso (otoneso.com) i EPRpilot (eprpilot.com).

- `index.html`: strona główna w stylu hero otoneso.com. Zdjęcie jest wbudowane w plik, więc to jeden samodzielny plik.
- `wlasciciel.html`: strona z danymi spółki (PL/EN).

## Publikacja (AttHost / DirectAdmin)

Wgraj oba pliki do `domains/viaregia.online/public_html`. Jeśli jest tam stary `index.php`, usuń go albo zmień mu nazwę. Potem włącz Let's Encrypt SSL dla domeny.
